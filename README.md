# ovk-bot-starter
Простая самописная микролибка для создания ботов в ОпенВК, лежит в core.

main.py - файл-демо с примером кода.

### ВНИМАНИЕ!!!
Помещение api в DI через processor.add_di() ОБЯЗАТЕЛЬНО! Иначе хендлеры не будут иметь доступа к нему.

- Pydantic
- httpx
